# Smart Register

Smart Register è un client alternativo per il registro elettronico, pensato per offrire un'esperienza moderna, fluida e completamente personalizzabile rispetto alle app scolastiche tradizionali.

---

## Features

* **Interfaccia Material 3 Expressive**: Design pulito, reattivo e ottimizzato per la navigazione quotidiana.
* **Personalizzazione Avanzata**: Personalizza colori, temi e layout dell'interfaccia per adattare l'app alle tue esigenze di consultazione di voti, assenze e argomenti.
* **Prestazioni e Fluidità**: Sviluppata nativamente per garantire caricamenti rapidi e consumi ridotti.
* **Automated Builds**: Build APK generate e pubblicate automaticamente nella sezione Releases grazie alle GitHub Actions integrate.

---
